# Alpha Smoke Test

Сценарии, которые надо пройти перед раздачей альфа-доступа. Если хоть один пункт ломается — баг, не альфа.

Прогон занимает ~30-40 минут на двух тестовых аккаунтах + одной тестовой группе.

## 0. Подготовка окружения

- [ ] Render Dashboard → `dead-spin-api` логи показывают `Migrations applied.` + `dead-spin api listening on http://localhost:3001 (prod)`.
- [ ] Render Dashboard → `dead-spin-bot` логи показывают `Bot @<username> is ready (prod)` + `Polling updates from Telegram...` (или `Webhook set to ...`).
- [ ] `https://<api-url>/healthz` отдаёт `{"ok":true,"env":"production","version":"<sha>"}`.
- [ ] `https://<app-url>/privacy.html` открывается, текст читается.
- [ ] UptimeRobot пинг настроен (или подобный сервис), последние ~3 пинга = green.
- [ ] У тебя есть как минимум второй тестовый Telegram-аккаунт (для дуэлей и group-сценария).

## 1. Регистрация и первый заход

С аккаунта-тестера, ранее НЕ заходившего в игру.

- [ ] Если `ALLOWLIST_OPEN=0` — сначала добавлен в allowlist (`pnpm --filter @dead-spin/api run add-tester <tg_id> "smoke test"`).
- [ ] `/start` в боте → приходит welcome-сообщение, нет ошибки «доступ закрыт».
- [ ] Кнопка «🎮 Играть» открывает Mini App.
- [ ] LoginScreen → нажатие PLAY → не больше 2-3 секунд → переход на интро/MainMenu.
- [ ] Если API спит и cold start затянулся: через ~12 секунд показывается «Сервер просыпается». После реального ответа — проходит дальше.
- [ ] Интро (3 кадра c1) проигрывается, можно скипнуть.
- [ ] MainMenu отображает: 0 звёзд, fuel ~30000.

## 2. Базовый игровой цикл

- [ ] Кнопка «Играть» в MainMenu → Levels.
- [ ] Видны все 15 уровней. Доступен только 1, остальные locked.
- [ ] Тап по уровню 1 → GameScreen загружается, корабль появляется в start-точке.
- [ ] Тап по экрану → буст работает, корабль летит вперёд.
- [ ] При попадании в стену → взрыв + ResultScreen «loose».
- [ ] Кнопка retry перезапускает уровень.
- [ ] Прохождение до финиша → ResultScreen «win» с количеством звёзд и временем.
- [ ] Кнопка next → GameScreen уровня 2.
- [ ] Кнопка exit → возврат в Levels. Уровень 1 показан как пройденный (с горящими звёздами).

## 3. Прогресс сохраняется

- [ ] Пройти 3-4 уровня подряд через next.
- [ ] Выйти в Levels → пройденные уровни горят, открыты следующие.
- [ ] Закрыть Mini App, открыть заново через бота → MainMenu показывает накопленные звёзды, Levels показывает прогресс.
- [ ] Сумма звёзд в MainMenu и в Shop совпадают.

## 4. Магазин и скины

- [ ] Открыть Shop → видно 5 карточек скинов.
- [ ] PROSPECTOR показан как SELECTED.
- [ ] Скины с requiredStars > 0 заблокированы (значок замка + «X/N⭐»).
- [ ] Если игрок набрал ≥8 звёзд — WANDERER разблокируется.
- [ ] Тап по разблокированному скину → SELECTED переходит на него.
- [ ] Закрыть Shop → войти в любой уровень → корабль теперь с новой текстурой.

## 5. Топливо

- [ ] Каждый буст списывает топливо (видно в TopBar).
- [ ] При <2000 включается красная пульсация по краям + sirens.
- [ ] При попытке зайти на уровень с <250 топлива → LowFuel-overlay «WAIT».
- [ ] Через несколько минут реальной паузы (или через DevTools `progressStore.getState().refresh()`) — fuel регенирует.

## 6. Сбои сети

- [ ] DevTools → Network → Throttle: Offline → попытка пройти уровень → ResultScreen всё равно появляется (recordLocal оптимистично).
- [ ] Online обратно → следующий рестарт уровня → API call успешен, прогресс уже на сервере.
- [ ] `/me/progress` через DevTools fetch → возвращает свежий progress.

## 7. Бот в DM

- [ ] `/menu` → главное меню с кнопкой play, ссылкой профиля, магазином.
- [ ] `/help` → справка с FAQ.
- [ ] `/feedback` → если `FEEDBACK_URL` настроен — ссылка на канал; иначе «канал не настроен».
- [ ] `/reset` → confirm-кнопки. Тап «Да» → progress обнулён. Открыть Mini App → MainMenu показывает 0 звёзд.
- [ ] `/reset` в группе → бот отвечает «работает только в личке».

## 8. Бот в группе

С тестового аккаунта-админа создать новый чат, добавить туда бота + второй тестовый аккаунт.

- [ ] При добавлении бота → `dead-spin-bot` логи показывают `my_chat_member` event. Запись в `group_chats` появляется.
- [ ] `/start@bot` или `/play@bot` в группе → бот шлёт сообщение «Dead Spin подключён» с url-кнопкой.
- [ ] Тап «🎮 Играть» → Mini App открывается. В TopBar нет ничего нового, но в game-screen появляется плашка беседы (вверху-справа) и ghost-плашка (вверху-слева — пустая если ghost'а ещё нет).
- [ ] Заметить что Levels показывает чистый прогресс (только 1 уровень доступен), даже если глобально игрок прошёл больше — group-isolation работает.
- [ ] Пройти 1 уровень → в чат прилетает нотификация «🚀 X прошёл уровень 1» с реакцией 👑 (первый лидер).
- [ ] Pinned-сообщение «🏆 Топ беседы» появляется (если бот админ с can_pin) или просто висит как обычное.
- [ ] Сделать бота админом с can_delete_messages → следующая `/lb` команда: твоё сообщение исчезает после ответа бота.

## 9. Группа: команды

- [ ] `/lb 1` в группе → таблица топа уровня 1.
- [ ] `/lb 99` → clamped к 15, показывает топ уровня 15 или «никто не прошёл».
- [ ] `/me` в группе → твоя статистика per-chat.
- [ ] `/best` → топ участников по сумме звёзд.
- [ ] `/setname Тестовая Команда` (от админа группы) → сохранилось. В Mini App плашка обновится после reload.
- [ ] `/setemoji 🚀` → плашка обновится.

## 10. Группа: ghost

- [ ] Пройти уровень 2 в группе.
- [ ] Выйти в MainMenu, потом снова в этот же уровень 2 → translucent-корабль (твой собственный ghost) проигрывается параллельно с тобой.
- [ ] Боостеры у ghost'а светятся синхронно с тапами по записи.
- [ ] При смерти ghost скрывается; при победе — остаётся висеть в финишной точке.
- [ ] Если второй тестер пройдёт быстрее → ghost сменится на его запись.

## 11. Группа: /challenge

- [ ] `/challenge @второй_тестер 3` → бот шлёт сообщение с дуэлью.
- [ ] Сыграть уровень 3 → бот промежуточно пишет «X сыграл, ход за Y».
- [ ] Со второго аккаунта пройти уровень 3 → исходное сообщение редактируется на «✅ Дуэль завершена» с победителем.
- [ ] Реакция 🏆 ставится автоматически.
- [ ] Повторно сыграть тот же уровень лучше → результат в дуэли НЕ обновляется (single-attempt rule), идёт только в обычный лидерборд.

## 12. Производительность

Проверить хотя бы на одном «бюджетном» Android-устройстве (≥3 года):

- [ ] Игра запускается без ошибок.
- [ ] FPS-counter (если включён) показывает ≥30.
- [ ] Звуки не запинаются, не задерживаются.
- [ ] Прокрутка/тапы отзывчивые.

## 13. После альфа-теста

- [ ] Sentry-дашборд (если DSN настроен) проверен на новые ошибки.
- [ ] Render-логи без `❌`/`Error`/`crash` за время теста.
- [ ] Все тестеры написали хотя бы что-то в FEEDBACK канал (или сказали «всё ок»).
