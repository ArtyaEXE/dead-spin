# Smoke-тест перед выкладкой

Ручная проверка того, что автотесты не покрывают: реальное устройство, сеть, звук.
Прогон — 10–15 минут. Если хоть один пункт красный — не выкладываем.

## 0. Сборка

- [ ] CI на ветке зелёный (Biome, типы, 74 теста, 30 уровней, обе сборки, docker).
- [ ] `docker compose --profile full up --build` → `/healthz` отвечает `{"ok":true,...}`,
      в логах `Migrations applied.`
- [ ] Версия в Settings совпадает с git-sha сборки.

## 1. Холодный старт (телефон, свежая установка)

- [ ] От иконки до главного меню — без экрана входа, без ожидания сервера.
- [ ] В авиарежиме игра запускается и играется; после включения сети очередь
      синхронизации уходит (в консоли нет `[sync] drop`).
- [ ] Прелоад показывает проценты и заканчивается; музыка не декодируется заранее
      (память процесса стабильна на прелоадере).

## 2. Ядро

- [ ] L1: тап — импульс, звук буста, дым. Финиш при скорости < 80 засчитывается.
- [ ] Гибель о стену: взрыв, тряска, экран результата через полсекунды.
- [ ] **Пауза рядом с миной → снятие паузы не взрывает мину.** То же при сворачивании
      приложения и возврате.
- [ ] Рестарт: сцена не «моргает», ретрай мгновенный.
- [ ] Таймер: 10 секунд игры ≈ 10 секунд по часам.

## 3. Рейтинг и прогресс

- [ ] Экран результата показывает три условия: финиш / время ≤ par / зачистка при расходе ≤ par.
- [ ] Перепрохождение медленнее, но с полной зачисткой — лучшее время **не** стирается.
- [ ] Сетка уровней показывает только CERES и PALLAS; звёзды рейтинга сохраняются
      после перезапуска приложения.

## 4. Профиль

- [ ] Дейлик: забирается один раз в местный день; перевод часов назад не даёт второй.
- [ ] Ачивка `first_clear` появляется в оверлее после первой победы, без сети.
- [ ] Смена скина и языка переживают перезапуск.

## 5. Звук на iOS

- [ ] Музыка стартует после «Играть» (жест), не раньше.
- [ ] Входящий звонок / Siri → после возврата музыка продолжается.
- [ ] Сворачивание → музыка на паузе, возврат → играет.

## 6. Сервер (если задеплоен)

- [ ] После победы `POST /progress/level-complete` уходит (Network 200), в БД строка в
      `progress_levels` с `par_hit`/`full_clear`.
- [ ] `PUT /me/profile` приходит после дейлика; `users.profile` обновился.
- [ ] Призрак глобального лидера виден на уровне, где он есть.
