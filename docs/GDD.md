## 1. High Concept

**Dead Spin** — однокнопочная физическая аркада. Зонд с повреждённым стабилизатором
непрерывно вращается; единственное, что работает — маршевый двигатель. Игрок не целится —
он выбирает **момент**. Пещеры астероидов, три звезды на уровень, мины, камни и черви,
финиш с ограничением скорости.

**Логлайн:** «Ракета вращается сама — ты решаешь, *когда* дать тягу. Один промах — взрыв».

**Идентичность.** Постоянное вращение 360°/с превращает управление в ритмическое: тап
попадает в «такт» оборота. Это и отличает игру от сотен пещерных аркад с рулением — здесь
нет прицеливания, есть только тайминг. Всё в дизайне (визуал, звук, обратная связь) должно
усиливать это ощущение такта, а не прятать его.

**Три кита продукта:**
1. **Ощущение** — мгновенный рестарт, читаемая гибель, near-miss, тактильный буст.
2. **Причина вернуться** — рейтинговые звёзды, призрак собственного рекорда, испытание дня.
3. **Честность** — никаких таймеров на аккаунте, реклама только по желанию игрока, за
   деньги нельзя купить рекорд.

## 2. Аудитория и платформы

|---|---|---|

основная платформа.

## 3. Core Gameplay Loop

### 3.1 Микро-петля — одна попытка, 10–90 с

```
спавн (0.9 с анимация вылета из дыры) → корабль вращается, vr = 360°/с
     ↓
тап → импульс BOOST_FORCE=50 вдоль носа, −100 топлива из бака уровня
     ↓
баллистика + гравитация уровня, стены, враги; сбор до 3 звёзд-предметов
     ↓
финиш: касание круга r=25 при скорости < 80 → WIN
     |
касание стены/врага → LOOSE → continue (если доступен) или рестарт
```

### 3.2 Мезо-петля — сессия, 3–10 мин

```
открыл игру → 🆕 испытание дня (если не сыграно) → кампания / бесконечный
     ↓
2–6 попыток на уровень → результат: звёзды рейтинга, время, сравнение с призраком
     ↓
следующий уровень / перепройти на 3★ / забег в бесконечном
```

### 3.3 Макро-петля — дни и недели

```
🆕 локальный пуш «новое испытание дня» → заход
     ↓
дейлик (монеты) → стрик → не пропускать
     ↓
призрак вчерашнего лидера в испытании дня → попытка побить
     ↓
звёзды → скины и следы; бесконечный режим → рекорд дистанции в Game Center / Play Games
```

**Time-to-first-fun:** цель — **≤ 15 с** от иконки до первого тапа. Было ≈ 60 с; прелоад
больше не декодирует музыку и не ждёт сервера, ассеты в 5 раз легче — 🔧 осталось сделать
комикс пропускаемым и убрать 0.9 с спавна на рестарте.

## 4. Controls & Feel

| Действие | Ввод | Эффект | Статус |
|---|---|---|---|
| Boost | тап по кнопке (`pointerdown`) | +50 ед. вдоль угла, −100 топлива | ✅ |
| Boost по игровому полю | тап в любом месте сцены | то же | 🆕 (сейчас `.game-host` с `touch-action:none`, но обработчика нет) |
| Rotate | автоматически, vr = 360°/с | не управляется — ядро механики | ✅ |
| Pause | кнопка HUD | заморозка физики и таймера | ✅ (мина на игровом времени — починено) |
| Zoom | UI 0.6×–1.4× | `localStorage['dead-spin.sceneZoom']` | ✅ |

**Удержание кнопки не даёт непрерывной тяги** — один тап = один импульс. Это осознанно:
серия тапов и есть ритм. Не менять.

### 4.1 Game feel — что добавить 🆕

Гибель мгновенная и без HP; в жанре это норма, но только при сильной обратной связи.

| Элемент | Спецификация |
|---|---|
| Near-miss | при проходе ближе 12 px от стены/врага без касания — короткий вспых по краю + лёгкий haptic; счётчик «на волоске» на экране результата |
| Hit-stop | 120 мс заморозки кадра в момент гибели перед взрывом |
| Мгновенный рестарт | ≤ 300 мс от тапа до контроля; сцена не пересобирается (§17) |
| Тактильный буст | haptic `light` на каждый тап (Capacitor Haptics) |
| Такт вращения | едва заметная пульсация свечения сопла в верхней точке оборота — визуальный метроном |

## 5. Физика и движок ✅

Чистая TS-реализация в `packages/engine/` — без зависимостей от DOM и рендера,
переносима в любой движок один в один.

- **Fixed-timestep loop** (`loop.ts`): dt = 1/60 с, аккумулятор, clamp кадра 0.25 с,
  фолбэк на `setTimeout` без rAF. `draw(alpha)` интерполирует корабль, камеру и
  параллакс между шагами — ✅ без джиттера на 120 Гц.
- **Collision** (`physics.ts`): sweep круга по полилинии, подшаги
  `ceil(speed·dt/radius·2)` — без туннелирования. Пространственный индекс стен по чанкам,
  строится один раз на уровень.
- **Apply force:** `(sin r, −cos r) · force`, 0° = вверх.
- **Гравитация:** глобальный вектор уровня, трения и демпфирования нет; скорость **не
  ограничена сверху**.
- **Детерминизм:** гарантирован для корабля (события ghost воспроизводятся точно).
  Враги **недетерминированы** — мина живёт на `performance.now()`, камень берёт `vr` из
  `Math.random()` на каждом отскоке. Для призраков это допустимо (призрак — только корабль),
  для честных дуэлей — нет. 🔧 при появлении соревновательных режимов перевести врагов на
  seed + fixed dt.

**Константы баланса** (`packages/shared/src/constants.ts`):

| Параметр | Значение |
|---|---|
| PLAYER_RADIUS | 30 |
| STAR_RADIUS | 20 |
| FINISH_RADIUS / FINISH_MAX_SPEED | 25 / 80 |
| BOOST_FORCE | 50 |
| FUEL_CONSUMPTION_PER_BOOST | 100 |
| MIN_LEVEL_TIME_MS | 3000 — ✅ не гейт, а флаг `suspicious_fast` в аналитике |
| Таймер | ✅ копится в float; раньше `Math.round(dt·1000)` давал +2 % |

**Тесты:** 47 юнит-тестов в engine (physics 12, vector 18, loop 3, mine-heat 14).

## 6. Сущности

### 6.1 Игрок ✅
Круг r=30, баллистика + гравитация, спрайт одного из 5 скинов с точкой крепления сопла.

### 6.2 Звёзды-предметы ✅
Ровно 3 на уровень, хитбокс 20 px. В v2.0 это **коллектиблы**, а не рейтинг (см. §9).

### 6.3 Финиш ✅
Круг r=25, скорость < 80, 800 мс анимация втягивания.

### 6.4 Враги (3 типа) ✅

| Тип | Поведение | Параметры в данных | Заметки |
|---|---|---|---|
| **Stone** | прямолинейно, упругий отскок от стен и друг от друга; дым при дистанции < 500 px | `radius` 35–42, `speed` 40–70 | vr случайный при отскоке |
| **Mine** | статична, ±5 px float; магнитный взрыватель с heat | `radius` 28–30 → детект 90–96 px | лучшая механика игры, см. 6.4.1 |
| **Worm** | 5 сегментов по 35 px по замкнутому B-сплайну через waypoints игрока | только `seed`; скорость 100 захардкожена | timing-перехват, а не «спрятан в углу» |

#### 6.4.1 Мина — heat (`packages/engine/src/mine-heat.ts`) ✅

| Константа | Значение | Смысл |
|---|---|---|
| MINE_DETECT_MULT | 3.2 | радиус детекта = radius × 3.2 |
| MINE_ARM_TIME | 2.5 с | непрерывно в детекте → heat = 1 → взрыв |
| MINE_COOL_DELAY | 0.5 с | пауза до остывания — анти-грейзинг |
| MINE_COOL_TIME | 3.0 с | полное остывание, медленнее нагрева |
| MINE_SWELL / SHAKE_AMP | 0.3 / 3 px | визуал: раздутие, покраснение, дрожь |

Единственная механика с внятной телеграфией без UI. Это эталон: **каждый новый враг
должен читаться так же** — по спрайту, без колец и подсказок.

#### 6.4.2 Червь ✅
Сплайн всегда через `startPoint → ★1 → ★2 → ★3 → finishPoint` с jitter ±110 px + 2
промежуточные точки. `safeFromPlayer` — стартовый сдвиг по сплайну. Регулировка
«жестокости» — сменой `seed`.

### 6.5 Декорации ✅
`static` (могут вмуровываться в стены), `gravity` (стрелка направления), `stop` (маркер).
Правила размещения — в памяти `feedback_level_design`.

## 7. Режимы игры

### 7.1 Кампания ✅🔧
30 рукотворных и сгенерированных уровней в двух мирах; последовательная разблокировка.
Переделывается: рейтинговые звёзды (§9), топливо уровня (§10), continue (§11), кривая (§8).

### 7.2 Бесконечный режим 🆕
Процедурная пещера без конца на существующем генераторе
(`packages/levels/src/generate.ts` — Perlin field + marching squares + DP simplify).

| Параметр | Значение |
|---|---|
| Генерация | сегментами по 2000 px впереди корабля, seed забега |
| Сложность | растёт по дистанции: ширина коридора 180 → 90 px к 20 000 px; плотность врагов 0 → 1 на 400 px |
| Топливо | канистры в стенах (+1500) каждые ~1200 px; бак 4000 на старте |
| Результат | дистанция в метрах (100 px = 1 м); лидерборд Game Center / Play Games |
| Continue | 1 за rewarded, 2-й за 200 монет, дальше — конец забега |
| Награда | 1 монета за 10 м |

Зачем: снимает потолок контента (сейчас 4–6 ч), даёт естественное место для rewarded
и лидерборда без сервера.

### 7.3 Испытание дня 🆕
Один сгенерированный уровень для всех игроков на 24 часа (seed = дата UTC).

| Параметр | Значение |
|---|---|
| Попытки | без ограничений, в зачёт лучшая |
| Continue | **нет** — иначе лидерборд бессмыслен |
| Призрак | вчерашнего победителя (сервер) или собственный вчерашний (офлайн) |
| Награда | 50 монет за прохождение, +50 за 3★ |
| Пуш | локальное уведомление в 10:00 по местному времени: «Новое испытание дня» |

Зачем: единственный повод открыть игру завтра, не требующий сервера пушей.

**Состояние на 22.09.2026.** Сделано: генерация уровня из даты, неограниченные
попытки с зачётом лучшей, липкий рекорд и рейтинг, серия дней, награды,
карточка в главном меню, экран результата. Не сделано и ждёт своего этапа:
призрак (нужна серверная таблица), пуш (нужен Capacitor, этап C), общий
лидерборд.

Уровень нигде не хранится — он пересобирается из даты. Генератор
(`packages/levels/src/procedural.ts`) прогоняет раскладку через те же
инварианты, что и кампания: если выпал непроходимый или скучный уровень,
сид отбрасывается. Замер на 30 днях: крюк 1.60–1.92 при цели 1.6, три мины
на уровень, все 30 собираются с первой-второй попытки.

### 8.3 Диагноз и целевая кривая 🔧

Что не так сейчас:
1. L1–L6 — шесть уровней без врагов (20 % контента — обучение).
2. Плотность врагов не растёт: максимум 5 взят на L11 и не превышен.
3. Коридоры не сужаются: 61–106 px без тренда за всю игру.
4. Стык миров — обрыв: L15 (5 врагов, 5329 px) → L16/17/18 ноль врагов.
5. **Генератор PALLAS стёр механику звёзд**: 8 уровней из 15 имеют крюк 1.02–1.09 —
   звёзды лежат на прямой к финишу. В рукотворном CERES крюк доходит до 4.47.
   Причина: в `generate-pallas.ts` звёзды заданы вплотную к точкам `mainPath`.

Целевые инварианты для любого уровня (проверяются скриптом `validate`):

| Крюк | ≥ 1.35 с L4; ≥ 1.6 с L10 |

### 8.4 Результат правки (2026-09-21, `scripts/tune-curve.ts`) ✅

## 9. Звёзды как рейтинг 🔧

Сейчас звёзды — предметы: собрал 3 → уровень закрыт навсегда, повода вернуться нет.
Уровень проходится с 0★. В v2.0 звёзды становятся **оценкой прохождения**:

| Звезда | Условие | Где задаётся |
|---|---|---|
| ★1 | финиш | всегда |
| ★2 | время ≤ `parTimeMs` уровня | JSON уровня, ориентир = 1.5× время автора |
| ★3 | собраны все 3 звезды-предмета **и** расход ≤ `parFuel` | JSON уровня, ориентир = 1.3× оптимума |

Что это даёт: причину перепройти каждый уровень трижды (быстрее, экономнее, полностью),
и естественный градиент «легко пройти — трудно закрыть на 3★». Карты не трогаем — только
два числа в JSON и логика подсчёта.

Максимум — 90★ на 30 уровней. **Награды до 90★**, а не до 45 (§12).

Хранение: `progress_levels` получает колонки `par_hit` (bool) и `full_clear` (bool);
`stars` — производное. Правило записи рекорда: звёзды не убывают, время и топливо
**улучшаются независимо** (сейчас при росте звёзд время перезаписывается безусловно — баг,
§17).

## 10. Топливо как ресурс уровня 🔧

### 16.1 Решение по движку
Остаёмся на TS. Переписывание на Godot/Defold (≈ 7 000 строк слоя отображения, 6–10 недель)
рассматривается только при **D7 ≥ 15 % и первом доходе**. Unity не рассматривается: его
преимущества (профилирование, охват устройств) не нужны 2D-игре с 20–40 спрайтами на сцене.
Физика и уровни переносимы 1:1 в любой движок — решение обратимо.

### 16.2 Офлайн-архитектура ✅
Источник истины — устройство. Сервер получает результаты через очередь отложенной
синхронизации (`stores/sync.ts`: порядок сохраняется, 4xx кроме 401 выбрасывается,
остальное ждёт сети). Без сети работает всё, кроме
чужих призраков и серверного лидерборда испытания дня. Это требование App Store
(Guideline 4.2) и условие честной работы continue.

### 16.3 Ассеты 🔧
Было 70 МБ. Картинки ✅ 31.5 → 6.7 МБ (`pnpm optimize:assets`, sharp: иконки в 256/512 px с
палитрой, фон в JPEG). Музыка ✅ стримится через `<audio>`, в `AudioBuffer` только SFX.
Осталось 🔧: сама музыка — 35 МБ, 74 минуты в 9 треках; цель 3–4 трека по 2–3 минуты
(нужен ffmpeg или выбор треков автором). Итог сейчас 44.5 МБ, цель ≤ 15.
