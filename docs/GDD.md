# Dead Spin — Game Design Document

Версия документа: v1.0 · 2026-05-10
Стадия проекта: pre-alpha (закрытое тестирование 5–10 игроков)

---

## 1. High Concept

**Dead Spin** — социальная физическая аркада в Telegram Mini App. Игрок ведёт постоянно вращающуюся ракету через тесные пещеры астероидов, собирает звёзды, уворачивается от мин, камней и червей и стремится в финиш с минимальным временем и максимумом звёзд.

**Логлайн:** «Ракета вращается сама — ты решаешь, *когда* дать тягу. Один промах — взрыв».

**Hook одной строкой:** не «ещё одна аркада в TG», а **аркада, которая живёт в твоём групповом чате**: pinned-лидерборд, ghost-replays соседа по беседе и `/challenge`-дуэли.

**USP / отличие от конкурентов:**
1. Pinned-лидерборд **per-chat** — каждая беседа со своим топом и ghost'ами лидера.
2. `/challenge @user N` — single-attempt дуэль 1v1 с asynchronous-резолвом.
3. Ghost replays через event-based recording (~1 КБ / прохождение) — призрак реально воспроизводится в твоём раунде.
4. Игра доступна там, где уже есть друзья (Telegram-чаты), а не «приведи друзей в новый клиент».

## 2. Целевая аудитория

| Сегмент | Описание | Что цепляет |
|---|---|---|
| **Core** | 18–35, мобильные казуальщики, активные TG-пользователи в групповых чатах | соревнование с друзьями, короткие сессии (30–90 сек на уровень) |
| **Secondary** | олдскулы Meteor-эпохи, фанаты Lunar Lander / Asteroids / Cave Hopper | физика, узкие коридоры, «ещё один попытку» |
| **Whales (потенциал)** | соревнующиеся в активных чатах | покупка Stars-fuel, чтобы не терять стрик дуэлей |

**Почему сейчас:** Telegram Stars + Mini Apps дают полноценный рантайм с платежами и identity без app-store фрикции; групповые чаты — недопиленный distribution-канал.

## 3. Core Gameplay Loop

### 3.1 Микро-петля (один уровень, 30–90 сек)

```
spawn → корабль вращается с постоянной vr=360°/сек
     ↓
тап / клик → ускорение по нос-вектору (boost = 50 ед., -100 fuel)
     ↓
лавируешь между стенами (ballistic + gravity), собираешь до 3⭐
     ↓
финиш-круг радиусом 15px, скорость должна быть < 40 → win
   |
столкновение с врагом или стеной → loose → restart
```

### 3.2 Мезо-петля (сессия, 5–15 мин)

```
открыл Mini App → daily check-in (если доступен) → выбор уровня
     ↓
играю несколько уровней → fuel падает → fuel ≤ 2000 = LOW_FUEL alarm UI
     ↓
fuel = 0 → варианты: ждать regen, потратить coins, купить Stars-pack, выйти
```

### 3.3 Макро-петля (retention, дни-недели)

```
push «бак полон» (24h cooldown) → возвращаюсь
     ↓
daily check-in: 7-day rotating reward (fuel/coins) → стрик → не пропускать
     ↓
group chat: pinned LB обновился, кто-то побил мой рекорд → играю реванш
     ↓
weekly digest в группе → виден рост / падение → социальное давление
     ↓
ghost replay лидера группы → пытаюсь побить → апаю скин по звёздам
```

## 4. Controls & Feel

| Действие | Управление | Эффект |
|---|---|---|
| Boost | tap / click hold | импульс +50 ед. вдоль текущего угла, -100 fuel |
| Rotate | **автоматически** vr = 360°/сек | игрок не управляет вращением — это и есть ядро механики |
| Pause | кнопка на HUD | замораживает физику и таймер |
| Zoom | UI (0.6×–1.4×) | сохраняется в `localStorage['dead-spin.sceneZoom']` |

**Ключевой ощущенческий конфликт:** ты не можешь «целиться» — ты можешь только *выбрать момент*. Это даёт кривую обучения «легко начать — глубоко мастерить».

Camera: follow + 7% parallax на заднем слое пещеры (`apps/game/src/game/GameWorld.ts:625-628`), tilingsprite `light.png` поверх для атмосферы.

## 5. Физика и движок

Чистая TS-реализация в `packages/engine/`:

- **Fixed-timestep loop** (`engine/src/loop.ts`) — детерминированный шаг для replay/ghost.
- **Vector math** (`engine/src/vector.ts`).
- **Collision** (`engine/src/physics.ts:96`): circle-vs-polyline sweep, `steps = ceil((speed * dt / radius) * 2)` подшагов — без туннелирования на больших скоростях.
- **Stone-vs-stone:** упругий обмен нормальными компонентами скорости (`GameWorld.ts:446-453`).
- **Apply force:** `(sin(r), -cos(r)) * force` — 0° = вверх (`physics.ts:28-32`).

**Тесты:** 33 unit-теста в engine — гарантия детерминизма для ghost-replays.

**Константы баланса** (`packages/shared/src/constants.ts`):

| Параметр | Значение |
|---|---|
| PLAYER_RADIUS | 30 |
| STAR_RADIUS | 20 |
| FINISH_RADIUS | 25 (требуется speed < FINISH_MAX_SPEED) |
| FINISH_MAX_SPEED | 80 |
| BOOST_FORCE | 50 |
| FUEL_CONSUMPTION_PER_BOOST | 100 |
| MIN_LEVEL_TIME_MS | 3000 (anti-cheat нижняя граница) |
| MAX_LEVEL_TIME_MS | 3 600 000 (1 ч) |

## 6. Сущности

### 6.1 Игрок (ракета)
- Hitbox: круг 30px.
- Физика: ballistic + global gravity vector уровня.
- Спрайт: один из 5 скинов (см. §10).

### 6.2 Звёзды (сбор)
- Ровно 3 на уровень (`star1`, `star2`, `star3` в JSON).
- Hitbox 20px. При сборе: invisible + SFX `star-catch`.
- Сумма звёзд за уровень = 0…3, копится в global `summaryStars` (для скинов).

### 6.3 Финиш
- Hole-спрайт + триггер-круг 25px + ограничение скорости < 80 (см. `FINISH_RADIUS` / `FINISH_MAX_SPEED`).
- При входе: 800ms анимация финиша, отправка `/progress/level-complete`.

### 6.4 Враги (3 типа)

| Тип | Поведение | Hitbox | Заметки |
|---|---|---|---|
| **Stone** (камень) | прямолинейное движение со скоростью `speed`, упругий отскок от стен и других камней | круг `radius` (обычно 40) | вращается с vr ∈ [−90, 90]°/с, дымы появляются при дистанции < 500px, SFX по дистанции |
| **Mine** (мина) | статична, ±5px float; магнитный взрыватель с heat-меткой (см. 6.4.1) | `r_kill = radius`, `r_detect = radius × 3.2` | прямое касание = instakill; в `r_detect` heat растёт за `armTime` 2.5 с до взрыва; «выгорает» одноразово |
| **Worm** (червяк) | 5 сегментов идут по замкнутому B-сплайну вдоль маршрута игрока (см. 6.4.2) | каждый сегмент 35px | speed=100, спавн-сдвиг по сплайну = «timing-перехват», а не «спрятать червя» |

#### 6.4.1 Мина — heat-механика (`packages/engine/src/mine-heat.ts`)

| Параметр | Значение | Смысл |
|---|---|---|
| `MINE_DETECT_MULT` | 3.2 | радиус детекта = radius × этот множитель (≈96 px при radius=30) |
| `MINE_ARM_TIME` | 2.5 с | сколько непрерывно в детекте → heat достигает 1.0 |
| `MINE_COOL_DELAY` | 0.5 с | пауза после выхода до начала остывания (анти-грейзинг) |
| `MINE_COOL_TIME` | 3.0 с | полное остывание (медленнее нагрева — возвращаться рискованно) |
| `MINE_SWELL` | 0.3 | максимальное «надутие» спрайта при heat=1 (× от исходного) |
| `MINE_SHAKE_AMP` | 3 px | амплитуда дрожания спрайта при heat=1 |

Визуал: **только сам спрайт**, никаких колец/арок. Heat ↗ — спрайт надувается, краснеет (tint `white → red` через розово-оранжевый), дёргается. Burn-out без kill (игрок ушёл в момент heat=1) — короткий 350 мс pop с alpha-fade.

Чистая heat-логика: `updateHeat(state, dt, inRange, nowMs)` в engine-пакете (14 юнит-тестов).

#### 6.4.2 Червь — маршрут вдоль waypoints

B-сплайн **всегда проходит через** ключевые точки уровня: `startPoint → star1 → star2 → star3 → finishPoint` с seed-зависимым jitter ±110 px + 2 случайные промежуточные точки. Это значит червь физически курсирует **тем же коридором**, что и игрок, а не где-то в углу карты (как было до 2026-05-18).

`safeFromPlayer` — больше не «спрятать в дальнем углу», а **timing-offset**: голова стартует в дальней точке маршрута, и пока игрок собирает звёзды — червь приближается по тому же сплайну, перехватывая в неудобный момент.

`seed` — короткая строка (1–3 симв.) только определяет jitter и порядок промежуточных точек. Один и тот же seed даёт одинаковую раскладку. Если игроки жалуются «червь жесток на этом уровне» — крути seed, маршрут будет смещаться вдоль waypoints.

Schema: `packages/shared/src/level.ts:45-75` (Zod discriminated union).

### 6.5 Декорации (3 типа)
- `static` — спрайт (debris, ship, stuff) с трансформом x/y/r/s; **могут вмуровываться в стены** для эффекта «вмёрзшего обломка» (см. feedback level-design).
- `gravity` — стрелка-индикатор направления гравитации (визуал; механика гравитации глобальная по уровню).
- `stop` — точка-маркер (визуальный hint для дизайна).

## 7. Контент: уровни и миры

### 7.1 Структура

| Параметр | Значение |
|---|---|
| Уровней всего (alpha) | **15** (`LEVEL_COUNT = 15`) |
| Миров | 5 × 3 уровня (`apps/game/src/game/worlds.ts`) |
| Формат | JSON, валидация Zod (`pnpm validate:levels`) |

**Поля уровня:** `name`, `res {x,y}`, `startPoint`, `finishPoint`, `star1..3`, `gravity {x,y}`, `walls[][]`, `decorations[]`, `enemies[]`, `intro?`, `outro?`, `referenceUrl`.

### 7.2 Миры (тематика — астероиды главного пояса, 15 уровней / мир)

| Мир | Уровни | Лор-тема | Палитра | Главный враг | Статус |
|---|---|---|---|---|---|
| **CERES** | L1–L15 | Ледяные каверны | голубовато-серый, бирюза, белые кристаллы | нет → мины+камни | ✅ |
| **PALLAS** | L16–L30 | Органические пещеры | тёмно-коричневый, чёрный, фиолетовые прожилки | мины (heat), камни, черви (L29-30) | ✅ |
| **JUNO** | L31–L45 | Кремниевые шахты | рыжий/охра, металлические серые | минные поля (dense grids), быстрые камни | ⚠️ пусто |
| **VESTA** | L46–L60 | Базальтовые пустоши | антрацит + красный, геотермальный | камни (bouncing, multiple, high-speed) | ⚠️ пусто |
| **EUNOMIA** | L61–L75 | Осколки | светло-серый/бежевый, яркие разломы | черви + комбо всего | ⚠️ пусто |

> **Главный bottleneck retention:** 3 из 5 миров пустые (JUNO/VESTA/EUNOMIA = 45 уровней). Решение — `dead-spin-level-generator` skill для процедурной/полу-ручной заполки + новые cave-текстуры для каждого мира.

#### 7.2.1 CERES — «Ледяные каверны» (L1–L15)

Церера — крупнейший объект пояса, карликовая планета с ледяной корой и подповерхностным океаном. Пещеры — пустоты в ледяной коре с кристаллами солей.

- **Текстуры**: мокрый лёд с прожилками, матовый камень, соляные наросты.
- **Свет**: мягкий рассеянный — ледяные линзы подсвечивают стены изнутри.
- **Декор**: замёрзшие обломки зондов, ледяные сталактиты, соляные кристаллы.
- **Настроение**: тишина, изоляция, «один в замороженном мире».
- **Геймплейная роль**: обучение. Управление → гравитация → простые враги. Пещеры широкие, прощающие.

#### 7.2.2 PALLAS — «Органические пещеры» (L16–L30)

Паллада — углеродистый, тёмный, богатый органикой. Стены покрыты органической массой, которая пульсирует. Машины предыдущих экспедиций вросли в породу.

- **Текстуры**: органическая масса, «мокрая» порода, прожилки-вены, грибовидные наросты.
- **Свет**: биолюминесцентные пятна — тёплые жёлто-зелёные.
- **Декор**: корни/щупальца на стенах, ржавое оборудование вросшее в породу, грибницы.
- **Настроение**: тревога, «что-то здесь не так», стены будто живые.
- **Геймплейная роль**: настоящие враги + нестандартная гравитация. Черви появляются как финальный шок (L29–L30).

#### 7.2.3 JUNO — «Кремниевые шахты» (L31–L45)

Юнона — силикатный, яркий, в кратерах. Промышленная добыча, заброшенные шахтовые тоннели. Кто-то заминировал выходы — чтобы никто не добрался до ядра.

- **Текстуры**: песчаник с лазерными ожогами, ржавые металлические фермы, решётки, рельсы.
- **Свет**: жёсткий, направленный — прожекторы горного оборудования, мерцание.
- **Декор**: бурильные головки, рельсы-вагонетки, оплавленные стены, предупредительные знаки.
- **Настроение**: клаустрофобия, индустриальный ад, «выходы заминированы».
- **Геймплейная роль**: мастерство мин. Heat-механика = центр геймплея. Коридоры узкие, мины густые (6–10 на уровень). Проскочить мимо 3 мин подряд, не дав heat подняться — skill ceiling.

#### 7.2.4 VESTA — «Базальтовые пустоши» (L46–L60)

Веста — протопланета с ядром. Лавовые трубки, колончатый базальт, нестабильные своды. Порода отваливается от потолка.

- **Текстуры**: колончатый базальт (гексагональные столбы), остывшая лава, глубокие трещины.
- **Свет**: геотермальный — красное свечение снизу, резкие тени. «Чёрный потолок — красный пол».
- **Декор**: базальтовые колонны, лавовые подтёки, геотермальные жерла, обугленные обломки.
- **Настроение**: хаос, всё движется, «этот мир не стоит на месте».
- **Геймплейная роль**: dynamic chaos. Камни = главный враг, их много, быстрые, отскакивают друг от друга. Мины ставят «замки» на перекрёстках.

#### 7.2.5 EUNOMIA — «Осколки» (L61–L75)

Эуномия — крупнейший осколок древнего столкновения. Астероид расколот, куски дрейфуют. Черви — единственная жизнь в разломах, охотятся на вибрацию двигателя.

- **Текстуры**: гладкий пористый камень, резкие сколы, «свежие» разломы.
- **Свет**: слепящий из разломов — прямой солнечный свет сквозь расколотый астероид.
- **Декор**: фрагменты породы в пустоте, солнечные лучи через щели, следы столкновений.
- **Настроение**: финал, масштаб, «ты прошёл всё — и вот последний вызов».
- **Геймплейная роль**: комбо всего. Каждый уровень — уникальная комбинация механик. L75 — финал: червь + minefield + bouncing rocks + strong gravity.

### 7.3 Визуальная прогрессия палитр

```
CERES      голубой-серый, холодный         ░░░░▒▒▒▓
PALLAS     тёмно-коричневый, органический  ▓▓▓▓████
JUNO       рыжий / охра, индустриальный    ░░▒▒▓▓██
VESTA      антрацит + красный, вулканический████▓▓▒▒
EUNOMIA    светло-серый + белые разломы    ░░░░░░▒▒
```

Каждый мир **визуально не похож** на предыдущий. Палитра от холодного к горячему и обратно к нейтральному. EUNOMIA как финал контрастирует со всеми — она *светлая* на фоне тёмных PALLAS/JUNO/VESTA.

### 7.4 Кривая сложности

- **L1 CERES #1:** 0 врагов, gravity = (0, 0), карта 1100×1000 → обучение управлению.
- **L15 CERES #15:** мины + камни, gravity diagonal, 2300×1900 → первый серьёзный вызов.
- **L30 PALLAS #15:** 1 worm + mixed enemies, gravity 2D → финал второго мира.
- **L45 JUNO #15:** dense minefield, tight corridors → мастерство heat-механики.
- **L60 VESTA #15:** bouncing rocks arena + strong gravity → контроль хаоса.
- **L75 EUNOMIA #15:** всё вместе → финал игры.

### 7.5 Level Design правила (закреплено в feedback memory)
- Пещеры **органичные**, не прямоугольные («fossilized cave», не «комната»).
- Корабельные обломки могут *вмуровываться* в стену — намёк на лор «кто-то здесь уже разбился».
- Каждый мир вводит свою **cave-текстуру** (пара tile-фонов: outer + inner), маппинг в `caveTexturesForLevel()` из `assets.ts`.

## 8. Нарратив

### 8.1 Тон
Минималистичный, сай-фай, без диалогов. Атмосфера ставится **цветом стен, звуком, обломками и тем, как мир пытается тебя убить** — не текстом.

### 8.2 Общий лор

Человечество послало флотилию автономных буровых зондов в пояс астероидов для разведки ресурсов. Каждый зонд — одноместный, с ИИ-навигатором. При потере связи зонд продолжает миссию самостоятельно.

Наш зонд попал в аварию (intro comic c1): удар, повреждение стабилизатора → корабль вращается неконтролируемо (*Dead Spin*). Единственное что работает — маршевый двигатель. Одна кнопка.

- **Звёзды** = маяки-датчики предыдущих экспедиций. Сбор маяков = разведка. Чем больше собрал — тем ценнее рейс.
- **Обломки в стенах** = предыдущие зонды, которые не вернулись. Вмурованы в породу десятилетиями. Не украшение — предупреждение.
- **Каждый астероид** — свой биом, своя угроза, свой визуальный характер. Зонд перемещается между ними последовательно.
- **Черви** — единственная жизнь в поясе, адаптировавшаяся к разломам Эуномии. Охотятся на вибрацию двигателя.

### 8.4 Расширение нарратива (в backlog)
- **Per-world intro comics**: короткие 2-3 панели при входе в новый мир (подход к астероиду → вход в пещеры → новый визуал).
- **Outro comic** по завершении каждого мира (зонд вылетает из астероида → прыжок к следующему).

## 11. Социальные фичи (USP)

### 11.1 Per-chat Leaderboard
- Таблица `group_progress_levels (chat_id, user_id, level, stars, time_ms)`.
- Сортировка: stars DESC → time_ms ASC.
- Доступно через `/lb [level]` или endpoint `GET /progress/group/:chatId?hmac=<12hex>`.
- HMAC по chat-context — защита от подделки.

### 11.2 Pinned LB
- Бот пинит сообщение со сводкой топа в группе, обновляет через `editMessageText`.
- `pinnedMessageId` в `groupChats` table.

### 11.3 `/challenge @user N` (1v1 дуэли)
- **Single-attempt:** первое прохождение игроком после вызова = его финальный результат.
- Сравнение: ⭐ DESC → ⏱ ASC.
- Timeout: **7 дней** (`DUEL_CLEANUP_MS`).
- Резолв: edit исходного сообщения + 🏆 reaction.

### 11.4 Ghost Replays (порт Tries.js)
- **Event-based recording:** start/boost/loose/win + `(t, x, y, r, vx, vy, vr)` на каждом событии.
- Между событиями — детерминированный ballistic + gravity.
- Размер: 10–30 событий ≈ **1 КБ / replay** (vs покадровая запись ≈ 100×).
- Валидация плейл-ности (`isPlausibleRecording`): монотонность времени, близость к start/finish (80px / 500ms).
- Ghost рисуется полупрозрачным спрайтом во время твоего раунда.

### 11.5 Group Streaks
- День, когда игрок в этом чате что-то закрыл = +1.
- Milestones: 3, 7, 14, 30, 60, 100 дней — нотификация **один раз** на milestone (`last_notified_milestone`).
- Пропуск дня → streak = 1, milestone-counter обнуляется.

### 11.6 Identity-контекст
- **DM** = глобальный прогресс, глобальные звёзды для скинов.
- **Group** = локальный per-chat прогресс и звёзды.
- Это сделано осознанно: игрок не должен вламываться в свежую беседу с фул-прогрессом — нужно «заработать репутацию» в новом чате.

### 11.7 Inline Mode
- `@<bot> ...` в любом чате → 3 article-результата с топ-уровнями игрока + ref-payload.
- Органический шеринг рекордов.

### 11.8 Команды бота (`apps/bot/src/handlers/`)
`/start [ref_<id>]`, `/menu`, `/help`, `/shop`, `/me`, `/lb [N]`, `/best`, `/challenge`, `/play`, `/setname`, `/stats`, `/reset`, `/feedback <text>`.

UI: HTML-форматирование, emoji-иерархия, inline-keyboards с editMessageText (одно сообщение, не флудит), expandable-blockquotes для FAQ, прогресс-бар топлива `█████░░░░░`, подсветка своего ника в LB.

**Тесты:** 56 зелёных (33 engine + 15 api + 8 bot). Все 15 уровней проходят Zod-валидацию.

### 14.1 Deploy
- **Mini App:** Cloudflare Pages.
- **API:** Render (Node.js, free-tier — спит после 15 мин idle).
- **Bot:** Render (webhook).
- **DB:** Neon PostgreSQL (managed).
- **Keep-alive:** UptimeRobot пингует `/healthz` каждые 5 мин.
- **Migrations:** автоматом на старте (`db:migrate && start:prod`).

### 14.2 Observability
- **Sentry** — error tracking (env-driven, `VITE_SENTRY_DSN` / `SENTRY_DSN`).
- **PostHog** — product analytics (env-driven, `VITE_POSTHOG_KEY`).

### 14.3 API endpoints (Phase 2)
| Метод | Путь | Назначение |
|---|---|---|
| POST | `/auth/telegram` | initData → JWT (7d) |
| GET | `/healthz` | health check |
| GET | `/me` | юзер с пересчитанным fuel |
| GET | `/progress` | summary + рекорды |

### 14.4 Известные риски
- **Race condition в `processGroupResult`:** group-write должен awaited завершиться до возврата 200; side-effects (нотификации, ghosts, streaks, achievements, pinned LB) идут fire-and-forget после (см. коммит `00dad93`).
- **Render free-tier sleep** — mitigated UptimeRobot'ом, но cold-start всё равно есть.

## 17. Open Questions

1. **Coins-расход:** механика «скрап-апгрейды ракеты» vs «магазин косметики» vs «лотерея»? Каждая гипотеза влияет на drop-rate коинов.
2. **Worlds-генерация:** ручная курация vs `dead-spin-level-generator` skill vs гибрид? Скиллом быстрее, но качество выше при ручной полировке.
3. **Public release:** через t.me/dead_spin_new_bot напрямую vs WL → волна? WL даёт качество фидбека, прямой запуск — больше данных.
4. **Tournament economics:** entry-fee в Stars / pool из Stars / просто bragging rights? Влияет на регуляторику Telegram.
